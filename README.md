# Miles Morales — Bento Landing Page

A fan-made, Spider-Verse inspired landing page built with plain HTML, CSS, and JavaScript.

## Run it

Just open `index.html` in a browser. No build step, no dependencies.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure (bento grid sections) |
| `style.css` | Bento layout, Spider-Verse theme, responsive rules |
| `script.js` | Scroll reveal, card tilt, lightbox, mobile nav |
| `assets/` | Local images (downloaded) |
